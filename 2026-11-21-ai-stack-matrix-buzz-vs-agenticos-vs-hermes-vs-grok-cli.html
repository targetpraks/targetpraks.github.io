What each one actually is

Standing, strengths, and the wall

Buzz Chat Block Buzz · retired here

A chat-first workspace with AI agents inside it: a self-hosted Nostr relay in Docker, a desktop and phone client, and managed agents that answer the owner only.

Wins
Humans and agents in the same room; phone pairing; local-first; one identity across your machines.
Wall
No scheduler, no governance, no company data, one canonical host per relay — and the identity is a key you must custody yourself.
State
no relay container · nothing on :10500 · app gone from /Applications · last work log 4 Nov
AgenticOS Infinity Brands · live, gated

An open-source, self-hosted company teammate platform: shared chat, RAG, browser, MCP, budgets, approvals and an audit trail, built on Pydantic AI. It carries your 22 company seats.

Wins
Real governance; 13 unit bots with routines; Zoho and ClickUp lanes; every write leaves a receipt.
Wall
Company scope only. Unit bots have no MCP of their own and only a snapshot feed, so they cannot query anything themselves.
State
web door 302 → Cloudflare Access · SSH path from this Mac down (bastion unresolved; macserver, infmini "No route to host")
Hermes v0.23.2 · live now

The agent runtime on this Mac: 35 profiles, 234 skills, 14 MCP servers, 11 scheduled jobs, 420 sessions and 137k messages, plus memory, channels, kanban and decision gates.

Wins
Deepest tool surface; always-on scheduling; the only one that remembers your estate; document publishing into the vault.
Wall
Single operator by design — no team roles, no shared company workspace — and it depends on the Mac mini staying awake.
State
hermes --version → 0.23.2 · sessions 420 / 137,255 messages / 1,561.5 MB · cron 11
Grok CLI grok 1.0.89 · unauthenticated

xAI's terminal agent: interactive TUI, headless mode, ACP agent mode, MCP, skills, subagents, hooks, memory, a real sandbox, and bring-your-own models including local Ollama.

Wins
Best coding ergonomics of the four; ACP means a T3 Code thread can host it; OS-level sandbox.
Wall
No scheduler, no chat surface, no knowledge of your estate — and it has never been signed in, so its value here is unproven.
