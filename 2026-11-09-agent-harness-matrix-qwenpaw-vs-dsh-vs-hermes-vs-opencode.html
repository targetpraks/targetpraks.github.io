  • QwenPaw is the only one built to live inside chat apps (17 channels incl. iMessage, WeChat, SIP, voice), with per-agent memory and multi-agent collaboration. Weakest on code, and on this Mac only the CLI remains.
  • dsh has the cleanest architecture of the five — profiles as ordered patch layers, sandbox/authorization/approvals as plugins, ACP and SDK as first-class profiles, Claude-Code hook protocol compatibility. No channels, no native memory: a coding tool, not an assistant.
  • Hermes is the only one with a closed learning loop (skills that write and improve themselves, curated memory, FTS5 recall) plus 20+ channels, cron with delivery, and profile fleets. It is also the heaviest.
  • OpenCode wins on coding ergonomics per unit of setup: 34 LSP servers, per-agent permission rules, MCP, runs on your own models. No scheduler, no channels.
  • Claude Code remains the best repo closer (git/PR/worktrees/plan mode, IDE + CI + mobile). Proprietary, cloud-bound, and logged out on this machine right now.

Caveats

  • Stars measure attention, not capability; QwenPaw is the youngest repo (created 2026-02-24) and the narrowest in scope.
  • "Local" columns reflect this Mac at 22:00 on 2026-11-09, not defaults.
  • Claude Code's 10 MCP servers report "connected" while auth is expired — sessions will fail until a human runs claude auth login.
