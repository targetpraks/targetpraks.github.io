3 · The section that was actually missing

A "CLI lanes" section — not a sixth model slot

You asked this morning whether the config needed another auxiliary section. It doesn't. But there is now a category the five sections cannot express: flat-fee capacity that arrives as a command-line tool, not an endpoint.

Antigravity/Gemini, Claude Code, Codex, omp, OpenCode are all in that bucket. They are already paid for, they are invisible to the model picker, and today each one is reachable only if an agent happens to remember to shell out to it.

That is the honest reason a section feels missing: the capacity exists, the wiring doesn't. It wants to be one row per CLI — command, quota, cost model, and what it should be used for — not another provider dropdown.

What I did about it now

  • Recorded the measured rule in the gemini-antigravity skill: escalate, do not migrate — hard reasoning goes to Gemini 4 Argon, volume stays on Ollama.
  • Wrote the invocation down with the flags that work: agy -p "…" --model gemini-4-argon-high --output-format json, run from a project directory.
  • Wrote the quota discipline in: read agy -p "/usage", a dozen escalations a day is nothing, a loop is theft.
  • Left the model config alone. Not one of the 36 homes points at Google, because none of them can.

5 · Money

Where the $129 goes

  • $120.91 — main lane. 88% of everything. Unchanged, and the only section worth optimising.
  • $5.9 — background review. Was $14.17 this morning before it stopped running on the main model.
  • $1.42 vision, $0.70 council, $0.05 titles — noise.

Google adds $0 to this. The subscription is already paid; the lane it buys is not metered.

The one lever Google does create

If the deep seat moved from glm-5.3 to Gemini 4, a hard-reasoning call goes from $0.0123 to $0 — but at 51 s instead of 1.5 s, and it needs an external-process provider written first.

At your current volume that is a few dollars a month. The prize is quality and quota headroom, not savings — which is exactly why it should be an escalation you choose per problem, not a seat that everything silently lands on.

6 · Decisions for you

1. Wire Gemini 4 as a real delegation route build

Hermes already has the plumbing for CLI-backed providers (external_process, the same shape as GitHub Copilot's ACP lane). Gemini needs its own provider profile pointing at agy acp, then deep can name it. Real work, maybe an hour, and it makes the subscription a first-class seat instead of a remembered shell command.

2. Main model → mimo-v2.6-flash $68/mo

Still on the table from this morning and unaffected by Google: identical on every probe I can run, 2.5× cheaper, worse at hard arithmetic. I'd trial it on one working profile before touching 36 homes.
