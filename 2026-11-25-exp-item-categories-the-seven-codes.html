How the code is chosen

  1. The item's own Zoho category decides the code — Uniform → UNI, Promotional → PRO, In-store → INS, Stationery → STA, Gifts → GIF, Online Marketing → ONL. Legacy zzUniform / zzPromotional map to the same two codes.
  2. An item with no usable category was assigned one by what it is, recorded in the plan so the change is visible rather than silent.
  3. The code is the second segment of the SKU: EXP-<CODE>-<ITEM>-<VARIANT>, upper case, hyphens only (EXP-STA-LABEL-50X33, EXP-UNI-WBREAKER-B-L, EXP-PRO-CAL-DESK-2025).
  4. OFF is defined in the standard but no EXP item uses it yet; it exists so office overhead never lands in STA or PRO by accident.
