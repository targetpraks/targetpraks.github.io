qmd search quality — embedder swapped, benchmarked before and after

What qmd is

@tobilu/qmd v2.8.3 — the fleet's local search engine over the Maio Hub vault. An MCP server on 127.0.0.1:8181 (KeepAlive) indexes the vault (2,285 files) into BM25 full-text + vector embeddings, re-ranks with an LLM, and is refreshed every 30 minutes by qmd-refresh.sh (qmd update && qmd embed). It runs entirely on this Mac — no query leaves the machine.

Three model roles in ~/.config/qmd/index.yml: embed (index vectors), rerank (orders candidates), generate (expands a query into lex/vec/hyde probes).

Method

30-query fixture built from the live vault: one sentence sampled from each of 30 notes, the note being the expected answer, expected_in_top_k = 5. Same fixture, same index, both models — qmd bench scores four backends (bm25, vector, hybrid, full pipeline).

Reading it honestly:

  • Recall is up where it matters: hybrid P@k 0.700 → 0.800, R@3 0.667 → 0.767, R@5 0.700 → 0.800. The right note is now inside the candidate set for 24 of 30 queries instead of 21.
  • Top-1 and MRR moved slightly down (R@1 0.567 → 0.467, MRR 0.653 → 0.602 at full pipeline). With 30 queries one query is 3.3 points, so this is 3 queries — inside the noise band, not a proven regression.
  • Full-pipeline precision is unchanged at 0.767; query latency is unchanged (10.3 → 10.7 s).
  • Qwen3 costs ~1.19 GB of resident model per context vs ~0.7 GB, and gives 1024-dim vectors with a 32k token window instead of 768-dim with 2k.

Decision

Kept Qwen3-Embedding-0.6B: it materially raises recall (the metric that decides whether an answer is reachable at all), holds full-pipeline precision, and is the newer, longer-context model. The top-1 dip is within sampling noise on 30 queries; a 60–80 query fixture would settle it and is the honest next step if accuracy at rank 1 matters more than recall.

Reranker (Qwen3-Reranker-0.6B) and query-expansion (qmd-query-expansion-1.7B) are the vendor's own tuned defaults for this pipeline and were left alone — the benchmark showed the embedder, not the reranker, was the weak link.
