7. The council's four rulings (hermes-council, 4 seats, 2026-11-13)

  1. Structure → (c) hybrid. "Numbered folders give the spec's order; prefixed list names keep them distinct in cross-Space views."
  2. Statuses → (b) API build now, status runbook to the owner. "The API silently accepts status writes and changes nothing."
  3. Chat → (a) delete the eight and rebuild the designed map. "Designed channels already exist; duplicates cause misrouting; topic is the only writable label."
  4. Fields → (b) spec placement rules only. "Roughly 400 placements cover real need; 2,400 is clutter."

The council's dissent, recorded because it is the real constraint on permissions: one Space per unit, 19 teams against a 10-team allowance and no API membership write means desk-level permissions stay a manual UI job until the owner's word changes the team model.

Its first-change advice — switch on the Custom Fields ClickApp in every Space before building anything else — is what made the 402 field placements possible at all; the very first field attempt returned 400 FIELD_605: A Custom Field ClickApp is not enabled in this location.
