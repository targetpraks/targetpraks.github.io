1. Root cause

ClickUp ties the timer to edit access on the location. A person at Comment level can see a task, change nothing, and cannot start a timer — the product returns TIMEENTRY_053. That level was set deliberately on 18 November: full edit for MANCO/EXCO, comments for everyone else, enforced list by list across every BU (371 person×folder pairs, ~370 person×list pairs, 63 chat channels).

So it was never a broken switch — it was the governance rule doing what it was told. Levels read from ClickUp's own permission service, not from a write's echo:
