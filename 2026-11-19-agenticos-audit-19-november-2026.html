4a. The 13:30 change, and the two minutes it cost

Enabling the browser lane stopped the stack once: browser-egress bind-mounts ./docker/browser-egress/squid.conf, Docker created that path as a root-owned directory on the first attempt (we have no sudo), the mount failed, and the dependent migrate/app/worker never started. Service was restored within about two minutes by pointing the overlay at nginx/squid.conf. The correct lesson: a profile service that bind-mounts a file must have that file before the profile is ever enabled.
