Why the nightly check said green

backup.sh promotes the dump when the file is ≥ 2,048 bytes, passes gzip -t, and the first 400 KB contain the string PostgreSQL database dump. A schema-only dump satisfies all three — an empty database dumps as a perfectly valid 5.6 KB gzip. (On 24 Nov the older 100 KB floor did reject the same empty dump; the floor was lowered to a structural check that night, so from 25 Nov the empty dump passes. The floor was not the real problem.)

Night-check's check_backups() (lines 708–737) inspects only hindsight/ and paperclip/, and only file mtime freshness — no integrity, no row counts, and it never looks at constellation/, home-assistant/ or top8/. That is why the 03:35 report read 🟢 backups | all fresh: hindsight, paperclip.
