3 · "Should we add another auxiliary section?"

No — the section already exists, it was just empty

Auxiliary already carries 22 task slots: compression, approval, review, MCP, title generation, memory-query rewrite, TTS tags, voice chat, triage specifier, kanban decomposer, profile describer, goal judge, group router, curator, monitor, background review, MoA reference, MoA aggregator and the three council slots.

Only vision had a model. Everything else was blank, and a blank slot means "use the main model" — so the section was decorative. Adding a sixth menu row would have created a second empty drawer, not a cheaper lane.

What is worth adding is a split inside Auxiliary: "interactive aux" (vision, compression, titles — quality matters) versus "background maintenance" (review, curator, monitor, triage — volume matters). That is a labelling/naming improvement, not a new config surface.

Where the missing seat actually was

  • Background review — 2,211 calls, cache-heavy (218k cached tokens per call), running at main-model prices.
  • Cache-read price decides this seat, not output price. At 218k cached tokens per call: mimo $0.0006, deepseek $0.0013, glm-5.3-flash $0.0065. The cheapest headline model (glm-flash) is the most expensive here.
  • So the new seat is mimo-v2.6-flash:cloud at effort low — and it is now live.
