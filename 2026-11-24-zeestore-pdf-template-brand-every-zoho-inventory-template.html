Exceptions and what the API cannot reach

Expense amount box stays Zoho green The expense template paints its amount box (#78ae54) inside a layout the API does not expose — balance_bg_color, amount_bg_color and similar keys are accepted but ignored. Fixing it needs a different gallery template chosen in the UI.
Modules with no API template record Sales Receipts, Shipments, Putaways, Quantity & Value Adjustments, Item Barcodes, Assemblies, Move Orders and Vendor Payments are built-in layouts without a template_id; the API returns them with null ids, so they cannot be restyled programmatically. They keep Zoho's default styling until a custom template is created from the gallery in the UI.
Elite receipt keeps its own layout The Payment Receipt template has no balance, terms or description fields — the standard brand colours were applied where the model allows.

How to re-run

  • python3 scripts/apply_pdf_template_brand.py — dry run, prints every field that would change.
  • python3 scripts/apply_pdf_template_brand.py --apply — writes the changes; a timestamped backup of all templates lands in data/template_backup_*.json.
  • python3 scripts/verify_pdf_template_brand.py — exits 0 only when all 16 match; writes data/template_verify.json.
  • Brand tokens live in brand/zee-store-brand.json; template ids in data/template_manifest.json.
