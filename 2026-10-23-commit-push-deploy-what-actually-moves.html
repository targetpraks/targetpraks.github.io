Save a file

You edit a file and save it. The change exists on this Mac immediately. Nothing else has seen it — not the history, not GitHub, not any running app.

If a development server is running with npm run dev, it reloads by itself and you see the change in the browser. That feels like a live update, but it is your own Mac re-reading the same file.
