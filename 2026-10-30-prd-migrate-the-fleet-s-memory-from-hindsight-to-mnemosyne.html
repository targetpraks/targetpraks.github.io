Migrate the fleet's memory from Hindsight to Mnemosyne

Twenty-nine profiles write their memory into a 3.58 GB container whose extractor lives at ollama.com. This is the plan to move them to a local engine that costs nothing, keeps what has already been learned, and can be reversed at every step.

01Summary

Twenty-nine Hermes configs point their memory at Hindsight. The free-only bake-off measured what that arrangement actually delivers: 20 of 22 questions answered at rank one, against 17 of 22 for Mnemosyne, which spent no tokens and sent nothing off the machine.

This PRD moves the fleet across, carries the 166,294 learned facts with it, and switches Hindsight off only after one profile has run clean for a week and the export has been verified twice. The trade is stated rather than hidden: recall gets slightly worse on multi-hop questions, and the stack gets much cheaper, much lighter and fully local.

What this PRD does not claim

It does not claim Mnemosyne is the better memory engine. Hindsight measured better on multi-hop and rephrased questions, and it is the only one of the two with entity resolution. The argument is operational: for a fleet writing memory on every turn, 29 times over, an engine that is nearly as good at a thousandth of the cost should be the default, and Hindsight becomes the tool we reach for when a bank genuinely needs graph reasoning.

03The move, in five phases

  • Phase 0 — Export. Page every fact and every document's original text out of the three banks into JSONL under AI-Drive. Counts and a sha256 per file. Nothing stopped, nothing deleted.
  • Phase 1 — Canary. Enable the plugin, switch this profile only, restart the gateway, run the probe set against a throwaway bank.
  • Phase 2 — Import. Replay exported facts into Mnemosyne in batches of 500, keeping each fact's original timestamp, and compare imported against exported per bank.
  • Phase 3 — Rollout. Two config lines per profile, in waves: scribe and beast first, then the executive seats, then the rest. Each wave runs the probe set before the next starts.
  • Phase 4 — Decommission. Stop the container and colima only after the fleet is clean. Hold the volume 14 days, then remove it on an explicit go-ahead.
  • Phase 5 — Freshness. Add hermes-dreaming for nightly supersession. Both engines failed that test, so it is a real gap, not decoration.

04Acceptance criteria

  • A1 — Export is complete. sum(1 for _ in open(<bank>.jsonl)) equals the bank's total from /memories/list. Pass: exact match, all three banks.
  • A2 — The provider is switched. hermes memory status prints Provider: mnemosyne. Pass: exit 0 and that literal line.
  • A3 — The canary retrieves. Ten single-fact questions from the bake-off, answered 10/10 at rank one. Pass: scorer.py reports hit@1=10/10.
  • A4 — Nothing leaves the machine. No established connection to ollama.com while memory is being written. Pass: lsof | grep -c ollama.com returns 0.
  • A5 — Import is complete. Facts in Mnemosyne equal facts exported within 0.5%. Pass: printed counts inside tolerance.
  • A6 — Prompt growth is measured. Record the tool-block token count before and after on one session template. Pass: recorded, and no more than +2,000 tokens.
  • A7 — Rollback was proved. Flipping the provider back returns a real memory id from maio-ops. Pass: one successful recall.
  • A8 — Reclaim is measured. After removal, the image and volume commands print nothing. Pass: both empty.
