2. Iron Man's schedules — the defect is fixed and proven

His sandbox was session_scope: "user". A user-scoped workspace needs a signed-in user, and a scheduled or API run has none — so every non-console run was refused with "This run has no signed-in user". Now session_scope: "agent" (published version 30): the workspace hangs off the agent, so a schedule always has one.

The host lane was also extended to agent-scoped workspaces (xa-), and the cron seeds any new workspace within five minutes.
