Terminal

  • ~/.local/bin/qwen → qwen-cloud (exports OPENAI_API_KEY, OPENAI_BASE_URL=https://ollama.com/v1, QWEN_DEFAULT_AUTH_TYPE=openai, then execs the keg). Qwen's default model pinned to deepseek-v4.1-flash:1017 in ~/.qwen/settings.json.
  • ~/.local/bin/mimo → mimo-cloud (exports OLLAMA_API_KEY).
  • ~/.local/bin/opencode2 → shim to the single brew binary (Orca's "OpenCode 2" detect name).
  • ~/.zprofile: ~/.local/bin forced ahead of /opt/homebrew/bin in non-interactive login shells (same path_helper workaround already used there for omlx and herdr; herdr-shims deliberately still first).

Orca (via its own runtime RPC — settings.update rejects agentCmdOverrides, settings.mutateAgentLaunch accepts it)

  • agentCmdOverrides: qwen-code → ~/.local/bin/qwen-cloud, mimo-code → ~/.local/bin/mimo-cloud.
  • agentDefaultArgs['mimo-code'] = "--trust" (MiMo's folder-trust prompt would otherwise block the pane; its --dangerously-skip-permissions adds a second blocking warning, so it is deliberately not used here).
  • disabledTuiAgents cleaned to ["opencode"] (the removed v1 slot). All 32 other yolo args restored intact after one settings.update write replaced the whole map — full map re-sent and read back.

Orca resolves agents from its own captured PATH, so a ~/.local/bin wrapper alone is not enough: the per-agent command override is what makes the Qwen lane authenticated.

T3 Code (~/.t3/userdata/settings.json, service restarted with launchctl kickstart)

  • pi provider instance removed.
  • acpRegistry_opencode_v2 converted to source: "local" → ~/.local/bin/opencode-acp (opencode acp).
  • Added acpRegistry_qwen → ~/.local/bin/qwen-acp (qwen --acp).
  • Added acpRegistry_mimo → ~/.local/bin/mimo-acp (mimo acp).

Readiness cache after restart (~/.t3/caches/<instance>.json): all three status: "ready".

5. Known quirks (not failures)

  • Orca prompt prefill: MiMo's flag-prompt submits itself; OpenCode 2 and Qwen Code only put the text in the composer (Qwen's is usually eaten by its first draw). Pressing Enter / retyping works — proven above. orca terminal read|send reports terminal_handle_stale until orca terminal switch --terminal <handle> focuses the tab.
  • Orca's OpenCode pane shows MCP server failed: maio-core: ~/.config/opencode/opencode.json points maio-core/maio-memory at 127.0.0.1:12008 with a bearer token that the gateway answers 401 to. Pre-existing, unrelated to these lanes; needs the current MetaMCP token or the entries disabled.
  • Qwen version string: qwen --version prints 0.26.1 while the Homebrew/npm keg metadata says 0.25.2. The binary is stable and functional; the mismatch is in the package's own version reporting.
