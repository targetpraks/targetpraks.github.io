04 Coverage — what this audit could not see

Honest gaps, so nobody assumes a clean bill of health:

  • No scope Zoho Campaigns — the token returns INVALID_OAUTHSCOPE on mailing lists. If a Titan campaign or autoresponder runs there, it is invisible to this audit.
  • No scope Zoho Flow — flow.zoho.com returns “URL not configured”. Flow flows that email cannot be inspected; only the CRM webhooks that feed them were seen.
  • No scope CRM Journeys — the journeys endpoint rejects the call; journey-based email is unverified.
  • Covered All 97 CRM workflow rules across 158 modules, all 393 email templates, and the Refer_a_Friend / Corporate_Refer_a_Friend modules — these are complete.

A · Switch the rule off

Deactivating the rule, not deleting it — reversible, and the definition survives if Titan ever revives the programme.
