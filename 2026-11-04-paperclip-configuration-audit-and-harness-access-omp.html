The one thing I did not do

Giving either runtime a real Paperclip seat means creating a principal that holds canCreateAgents and canCreateSkills inside a live company — and this instance requires board approval for every new agent. That is your signature, not mine. The payloads are ready:

// 1 — OMP gets a seat via the documented pi_local adapter (it accepts a custom binary)
POST /api/companies/<companyId>/agents
{ "name": "Omar Pi",  "role": "engineer", "adapterType": "pi_local",
  "adapterConfig": { "command": "/opt/homebrew/bin/omp",
                     "model": "ollama/deepseek-v4.1-flash:1017-cloud",
                     "cwd": "/Users/ricardomaio" } }

// 2 — DeepSeek has no native adapter; nearest honest options are a process seat
//     wrapping `dsh headless`, or leaving it harness-only. Not a same-day build.
POST /api/companies/<companyId>/agents
{ "name": "Deep Sea Connors", "role": "engineer", "adapterType": "process",
  "adapterConfig": { "command": "/opt/homebrew/bin/dsh",
                     "args": ["headless", "{{prompt}}"], "timeoutSec": 1800 } }

// 3 — then an agent key per seat, and never a shared board trust again
POST /api/agents/<agentId>/keys

The honest caveat on (2): the process adapter has no session memory and no tool policy, so a DeepSeek seat built that way is a runner, not a colleague. If you want it to behave like the others, the right answer is a paperclip acp adapter upstream — OMP already fits pi_local, DeepSeek does not fit anything yet.

4 · What I recommend, in order

  • Approve a first wave, not thirty. CTO, CMO, CFO, COO for one company — after D4 is repointed, or they die on their first ticket.
  • Narrow the Zoho MetaMCP namespace behind mcp-zoho. 95 servers and 14,550 tools in every prompt is what breaks D2, and it burns tokens on every harness that mounts it.
  • Decide the trust model. Either accept that anything on this Mac is the board, or give the harnesses agent keys and stop relying on loopback. Do not leave companyDeletionEnabled true on top of total local trust.
  • Archive the seats nobody will use. Seven C-suite seats on day one, in a company with no reports, is capacity theatre; park CRO, CHO, CAO until there is work.
