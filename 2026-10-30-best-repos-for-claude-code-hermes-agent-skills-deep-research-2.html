Short answer

The single best repo to install first is mattpocock/skills (github.com/mattpocock/skills, ~305k stars). It covers all four of your areas with small, composable, model-agnostic skills that install into Claude Code, Codex, Copilot, Gemini CLI, and any other agent. For Hermes Agent specifically, the bundled skills catalog ships 82 built-in skills (plus a 117-skill optional catalog) covering testing, debugging, planning, and design — and ZeroPointRepo/awesome-hermes-skills is the curated community directory for more.

Below is the breakdown by area, with repo names, what each skill does, and how to install.

plan-design-griller Rigorous technical interviewer that systematically challenges software architecture and feature proposals MCP Market (mcpmarket.com) Claude Code / MCP agents

The grill-me mechanism (from the skill itself): questions are asked in rounds — each round asks the whole "frontier" of decisions whose prerequisites are settled, numbered with a recommended answer, worded so "yes" accepts the recommendation. The session ends when the frontier is empty and you confirm shared understanding.
