🔴 1. The nightly backup did not run at all this morning

com.maio.backup fired at 03:30, the night check kicked a re-run at 03:35, and both died in the same place — before a single lane completed. launchctl print gui/501/com.maio.backup reports runs = 2, last exit code = 1.

Log, verbatim (~/Library/Logs/com.maio.backup.log):

[2026-11-26 03:30:06] backup start (v4)
/Users/ricardomaio/.config/maio-stack/secrets.env:1501: missing delimiter for 'u' glob qualifier
[2026-11-26 03:35:27] backup start (v4)
/Users/ricardomaio/.config/maio-stack/secrets.env:1501: missing delimiter for 'u' glob qualifier

Root cause. backup.sh line 37 runs set -a; source "$HOME/.config/maio-stack/secrets.env"; set +a under set -euo pipefail. Line 1501 of secrets.env is the last key in the file — ZOHO_SUPERMAN_ISSUED_BY — and its value is unquoted while containing a parenthesis. zsh reads the parenthesis as a glob qualifier, fails the parse, and source returns 1; set -e then aborts backup.sh before the first lane. Measured, values not printed:

$ zsh -c 'set -euo pipefail; set -a; source ~/.config/maio-stack/secrets.env; set +a; echo REACHED'
secrets.env:1501: missing delimiter for 'u' glob qualifier
real_exit=1

All 197 keys above line 1501 load correctly (verified by name only — 197 of 197 present in the environment after sourcing); the failing key is the last one, so nothing else in the file is lost beyond that single variable and the abort itself.
