2. The gate

~/.agents/ship-small/check — Python 3 standard library only, plus git and gh. It is the only place the rules live; every hook is an adapter that calls it.

  • Blocks in scope: commit on the default branch · push to the default branch · force push (allowed as --force-with-lease on a non-default branch) · --no-verify (and git commit -n) · gh pr merge · gh pr review --approve
  • Blocks everywhere: gh api writes to rulesets, branch protection, repo/org settings; gh repo|org edit|delete
  • Warns, never blocks: a branch past 300 changed lines (lockfiles, build output and tests excluded)
  • Fails open on anything it cannot parse
  • Appends every decision to ~/.agents/ship-small/log.jsonl

3. Git hooks — the layer that catches everything else

git config --global core.hooksPath = ~/.agents/ship-small/git-hooks (it was unset before this install).

  • pre-commit — blocks a commit on the default branch, warns past 300 lines
  • pre-push — blocks a push whose destination is the default branch
  • Each hook first runs the repository's own hook of the same name, so nothing existing was displaced
  • In-scope repos only; every other repo passes straight through

This is what covers T3 Code's commit and push buttons, and any tool added later that does not get its own hook.

5. What is not covered, and why

OpenCode 2.2.0. It loads plugins from ~/.config/opencode/plugins/, but the installed build's plugin API does not expose a pre-command hook that can refuse a call. Proven by instrumenting a plugin: the loader accepted it, no handler fired, and git commit --no-verify went through. The inert plugin was removed rather than left pretending to guard. OpenCode keeps the skill and the git hooks, so commits and pushes on main are blocked; the gap is --no-verify, force-push and gh pr merge.

Force push at the git layer. Git does not pass the flags to pre-push, so a plain --force and a --force-with-lease look identical to a hook. Force push is therefore blocked by the tool hooks (Claude Code, Codex, omp, Qwen Code, Hermes) and not by git itself — which is what the brief specified for the git layer.

Codex trust. A new hook in hooks.json is inert until a human reviews it. Open Codex, run /hooks, approve ship-small. Until then Codex has the skill but no pre-command block.

Hermes gateway. New shell hooks register at gateway start. The hook is allowlisted; a running gateway picks it up at its next restart.
