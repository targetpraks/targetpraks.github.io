3. The one step the API refused

Status vocabulary is still ClickUp's default

Every list still runs Open · in progress · in review · waiting · blocked · completed. Writing statuses through the API is refused — four request shapes, all answered 400, "Status name is required" — and there is no documented endpoint for it. This is a Space-settings change:

  • Weekly lists: not started · in progress · concluded
  • Monthly list: not started · in progress · submitted · reviewed

Until that is set, the Submitted → Reviewed handshake cannot run. Everything else is in place and waiting for it.
