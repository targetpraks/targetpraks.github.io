# PRD — Extreme Ownership List (MANCO) v1.0 **Date:** 2026-11-26 · **Owner:** Ricardo Maio · **Author:** Bruce Wayne · **Status:** DRAFT — 5 decisions open (§10) **Build target:** ClickUp list `1501000000003567` "Extreme Ownership" in the MANCO space, verified live today. --- ## 1. The product in five lines 1. One board in MANCO where every failure that hit the company gets owned in full — What. Why. Fix. 2. Every card carries **Brand**, **Business Unit** and **Section**, so a failure is findable by where it lived. 3. Every card carries a **Recurrence** flag — First time, Repeat, Chronic — so the twice-rule is visible, not remembered. 4. The Section filter is the payoff: when the same thing threatens to happen again, the history of that section failing across every BU is one filter click away — before it happens, not a month after. 5. MANCO reads it in the weekly, and nothing repeats without a system change on record. ## 2. Stack, fixed in one paragraph The product is **ClickUp configuration only** on the existing workspace (Infinity Brands, plan `Business`): one list, three list-level custom fields, one template task, four list views. No code, no third-party tool, **no automations** — workspace history shows an automation that silently falsified due dates had to be killed by hand; this build uses none. The list, its statuses and two of the fields already exist and were read back from the live API today; everything else is listed in the build order (§7). Nothing migrates: the list starts empty and fills from Monday's real work. ## 3. The build order assigns each step to the honest lane. ## 6. The protocol (how the rule lives after the build) 1. **Filing:** finder files the card the day the failure is found, fills WHAT on the spot; WHY and FIX can land same day. A Repeat card links to the first card (native task link) — the paper trail of a pattern is two clicks deep. 2. **Weekly — 5 minutes of MANCO Weekly** (Nadine chairs): walk V4 Repeat Watch. A `Repeat` closes only when the Fix names the **system change**; a `Chronic` comes to Ricardo with the system-change proposal attached, because three strikes are a business decision, not a task. 3. **Close rule:** no card closes without a Fix line showing a person and a date; a Repeat or Chronic closes without a system change recorded in the Fix is not a close — reopening is one click and MANCO sees it happen. 4. **The promise the list makes:** the first failure is training; the second is a decision. Nobody at MANCO should ever meet failure number three unannounced. ## 7.
