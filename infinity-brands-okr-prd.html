5. The four words

5.1 One controlled vocabulary

Every Key Result and linked KPI has exactly one Type. The HOD master uses 51 distinct type strings and 158 pillar strings for four types and three pillars. (V3, 04 HOD KPI Master, type and pillar columns.) The register is:

Type Question Required definition
Action Was the required work completed by the required deadline or SLA? Deadline or SLA · Evidence
Outcome What changed because the work happened? Baseline · Target · Direction · Unit · Source
Control Was the work correct, controlled and supportable? Standard · Sample · Pass/fail rule
Leadership Did the named team or process become measurably better? Baseline · Target · Named team · Source

Two rules are mandatory:

  • An Action may never be the only measured result for a role. There must be at least one Outcome unless an Action-only exception is explicitly approved.
  • Completing an Action never proves that its intended Outcome was achieved.

For commitment authoring, the practical consequence is direct: a list of activities cannot pass as a set of key results merely because each activity has a deadline.

9. Quarterly targets become monthly targets

9.1 Activation rule

Every quarterly Key Result carries a target for each month in its quarter. The sequence is authored at activation. A Key Result without a complete monthly sequence remains Draft, with the missing sequence named.

The monthly sequence lives in the engine, one row per month. Capture points to that row. ClickUp displays the commitment period and review state; it does not hold a second editable copy of monthly actuals or computed progress.

9.2 Decomposition is by metric behaviour

Behaviour Quarterly-to-monthly rule Forbidden shortcut
Flow — count or total Monthly amounts sum to the quarterly amount Treating a cumulative value as a new monthly amount
Cumulative — year-to-date Store cumulative values; never sum them into a quarter total Adding cumulative values together
Stock — value at a point Store the value for each month; no split Dividing headcount or point-in-time ARPU into parts
Rate — percentage or ratio Store numerator and denominator separately; derive the period rate from them Averaging monthly percentages
Milestone Store the milestone date and binary completion state Inventing a numeric target for a binary result

The engine states the fiscal calendar once: financial-year start month, quarter boundaries and treatment of a 53-week year. The source sheet's Q1–Q4 labels alone do not define that calendar.

A week belongs to the month containing its last working day. That rule is stated once and used by every capture row, so the same week cannot enter two monthly periods.

The live pilot in PRD-B §11.1 tests this target model in operation — one BU, one month, read-only live files. It does not relax the activation gate, and no key result scores before that pilot closes.

13. What we will not do

  • No fifth spreadsheet. A new file requires an existing file to be retired.
  • No actuals or typed computed percentages in ClickUp. It authors commitments and reads results.
  • No quotas. The gate decides how many commitments become Active.
  • No invented numbers. A blank with a named owner is preferable to a plausible guess.
  • No arithmetic inferred from alignment. A parent is a home, not an instruction to sum children.
  • No deletion of commitments. Retirement preserves the object and its ID.
  • No mirror of the business. A 485-task mirror with its own Actual field was designed, measured and rejected: it gives every number a second writer.
  • No live write without explicit approval. Copies, rehearsal and rollback proof come first.
