Kit notes & caveats

  • theme.css re-declares all 19 of the page's :root names with light values, then adds 27 kit tokens (--cyber-*, --radius*, --shadow-*, --*-soft, --*-line, --gold-bright, --gold-soft, --venture, --hair, --ring*). Link it after the inline <style>.
  • Contrast is audited against --panel2 (the darkest surface a text token can land on): the worst text token is 4.64:1, and every text token clears 4.5:1.
  • Zero !important. The mobile block's .win{…!important} geometry is left untouched — none of these rules set the same properties.
  • --gold is now two tokens: --gold #82650F carries text (5.0:1); --gold-bright #C9A227 is the original brand accent, kept for fills, borders and the logo.
  • The page's dark-theme #c9a0e8 venture swatch is replaced by the token --venture #6D4497.
  • Traffic lights go from grey-on-hover to always-coloured — a deliberate cartoon touch; revert by deleting the .wl block.
  • @media (prefers-reduced-motion:reduce) in the page already kills all animation; the kit adds only short transform/shadow transitions.
