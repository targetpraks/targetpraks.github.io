PRD: dsh-maio-nexus — Unified DeepSeek Harness Plugin Suite

Target: Web profile (dsh web) + Official DSH Desktop App · Integration: Hermes Memory + Beast / OpenKnowledge Vault (AI-Space) · Staged by Adrianna A, review & manual install by Ricardo.

Executive Summary. This PRD specifies a custom, production-grade DeepSeek Harness (DSH) plugin suite — dsh-maio-nexus — designed specifically for Ricardo's local Mac stack. Rather than using disconnected plugins, this suite unifies two critical capabilities: (1) Shared Memory Synchronization with Hermes Agent memory stores, and (2) Obsidian Vault Recall via Beast and OpenKnowledge (OK), allowing DSH sessions to seamlessly reference markdown notes across AI-Space without duplicating state.

1. Vision & Problem

Problem: DeepSeek Harness sessions operate in isolation. When running tasks in DSH, agents have no awareness of historical user preferences stored in Hermes memory, nor can they query the Obsidian vault (Maio Hub) for architecture specs, PRDs, or guidelines.

Solution: dsh-maio-nexus bridges DSH to the local Mac stack. It registers custom Cordis plugin handlers that hook into DSH session context injection, providing zero-latency FTS5/vector recall over Hermes memory and read-only semantic search over the Beast vault.

3. Feature Specification & Acceptance Criteria

  • F1: Hermes Memory Integration (P0) — Automatically injects relevant user preferences and cross-session facts into the DSH system prompt.
    Acceptance: DSH sessions correctly recall user constraints without manual prompting.
  • F2: Obsidian Vault Semantic Recall (P0) — Registers tool vault_recall allowing agents to query markdown notes within AI-Space (Research, Work, PRD).
    Acceptance: Agents fetch exact markdown snippets from vault notes with zero modification to read-only vault files.
  • F3: Dual Target Deployment (P1) — Packages cleanly into a standard DSH bundle installable via CLI (dsh plugin add) and manageable via Desktop settings.
    Acceptance: Installs without breaking core DSH components or requiring root privileges.
  • F4: Nightly Sync via Courage (P1) — Reindexes vault and memory caches nightly via Courage cron jobs.
    Acceptance: Background reindexing completes silently with zero UI interruption.

4. UX & UI Design

The plugin adds a clean settings panel under DSH Settings → Maio Nexus, featuring:

  • Connection status indicator for Hermes Memory and Beast / OpenKnowledge.
  • Vault Scope selector (AI-Space default, read-only enforcement).
  • Token usage and recall latency telemetry.

5. Non-Functional Requirements

  • Security: 100% local execution. No credentials or vault contents leave the machine. Read-only access to the Obsidian vault guarantees Beast remains the sole writer.
  • Performance: Local FTS5 vault recall returns in < 50ms.
  • Fail-Closed: If OpenKnowledge or memory stores are unreachable, DSH agents proceed with standard context without throwing fatal errors.
