Four things the tweet does not tell you

1. The stock ffmpeg cannot do half this lane. Homebrew's ffmpeg 9.0.2 ships without libvidstab, libfreetype or libass — drawtext, subtitles, vidstabdetect and vidstabtransform all returned nothing. ffmpeg-full is the fix, it is keg-only, and it coexists with the existing binary. Burned-in text and stabilisation are impossible without it.

2. pip install realesrgan is broken on Python 3.13. Its dependency basicsr is sdist-only and its setup.py dies with KeyError: '__version__'. The working path is the official ncnn binary — a universal M4-native build — or spandrel 0.4.2, which loads the same checkpoints with no basicsr at all. Both are installed.

3. Demucs is archived. Meta shelved facebookresearch/demucs in April 2024. The pip package still works perfectly, but it is a dead branch: no fixes are coming.

4. RIFE and Real-ESRGAN are 2022–2024 vintage. Both need a downloaded binary rather than a package manager, and neither has been updated this year. They work; do not expect them to track new hardware.

Defects found and fixed during the build

  • QC failed twice before it passed. First on frozen frames (a static test pattern plus a static title tail) and again on loudness (−32 LUFS). Fixed by giving every shot real motion, adding a continuous animated element to the title card so no frame is static, and running loudnorm to the −14 LUFS target.
  • The title card rendered wrong at first. Built as a CSS flex column, it laid out correctly in a browser but HyperFrames' capture viewport re-flowed it: the kicker and the rule landed inside the headline. Rebuilding every element with absolute coordinates fixed it. Pixel measurement of the final frame now shows five clean bands — kicker 230, headline 279–334 and 360–429, rule 470, feature strip 506 — with 31–40 px of air between each.
  • Two vision reads of these frames were wrong (they invented text overlaps and a green edge line that pixel inspection disproved at 30/30/25 mean RGB). Where a model and the pixels disagree, the pixels win.

How to use it

The whole lane is driven from ~/AI Hub/video-stack/.venv plus ~/AI Hub/video-stack/bin. The worked example, with every script and every intermediate artefact, is /Volumes/Hiksemi 1TB/AI-Drive/Agent-Output/adrianna/editor-lane-proof/:

  • make_footage.sh — builds the test clip
  • final_export.sh — title card + cut + burned-in captions + loudness, one command
  • final_film.mp4 — the finished 24-second film
  • titles/ — the HyperFrames title card project

The honest limit: this is a pipeline, not an editor. It will cut, steady, grade, slow, upscale, stem, title and export anything you hand it. It will not tell you the cut is good — that remains the only part of editing nobody has open-sourced.
