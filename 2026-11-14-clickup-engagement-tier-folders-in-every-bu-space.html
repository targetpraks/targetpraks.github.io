Correction to the first build

The first pass flattened the tier+brand into single folders (ZOR - EXP, …) on the claim that ClickUp cannot nest folders. That claim was wrong. ClickUp supports exactly one level of subfolders (Space → Folder → Subfolder → List), and this Workspace has it enabled. Proven live before rebuilding:

POST /space/901211092557/folder  {"name":"ZZ Probe Parent"}                         → 901215910244
POST /space/901211092557/folder  {"name":"ZZ Probe Sub","parent_folder_id":"…244"}  → 901215910245
POST /folder/901215910245/list   {"name":"ZZ Probe List"}                           → 901223608153
GET  /space/901211092557/folder   → both entries, the sub carrying parent_folder 901215910244

Both probes deleted afterwards. Sources: ClickUp Help "What are Subfolders?" (one level only) and the API reference for Create Folder (parent_folder_id) and Get Folders (parent_folder, flat list).

Subfolders carry the tier in their name (ZOR - EXP) because ClickUp requires folder names to be unique within a space — a bare EXP under ZOR collides with EXP under ZEE, and in Brand Ops 1/2 it also collides with the existing top-level brand folders.

List names carry the whole coordinate and stay unique per space: {CODE} {TIER} [{BRAND}] {LANE} — FIN ZOR EXP Briefed-In.
