3. The model

Admin Manco Staff
ClickUp workspace role Admin Member Member (or Limited member — see §5)
Access granted at whole workspace the Spaces they run — Full edit their desk's Lists — Edit
Create tasks yes yes no
Change dates / status / assignee yes yes yes (on tasks in their lists)
Delete tasks yes yes (unless §5 Q1 says admin-only) no
Create Spaces yes no no
Manage people, statuses, fields yes no no
Edit other people's tasks yes yes, in their Spaces yes, in their lists — but they cannot create or delete

Why this mapping works: ClickUp does not have a "create tasks" permission at all — creation is implied by having Full edit on a location, and denied by Edit. So the tier that may create (Manco) gets Full edit; the tier that may not (Staff) gets Edit. Delete follows the same line: Edit cannot delete.

4. How each tier is set

Admin — Settings → People → the person → role Admin. Owner stays Ricardo.

Manco — invite as Member, then on each Space they run: Space → ⋯ → Share → add the person → Full edit. (Space is private, so this is also what makes it visible to them.)

Staff — invite as Member (or Limited member), then share only their desk's Lists — List → Share → add the person → Edit. They see those lists and nothing else in the Space; inside them they can open, edit, comment on and move tasks through the statuses, but the Add Task button is refused and no delete action is offered.

Guard rails to set once (Settings → Security & Permissions → Role Permissions, Member column):

Setting Now Set to Why
Create Spaces ON off closes the one real hole: a staff member who could create a Space could then create tasks inside it
Importing ON off no bulk task creation by import
Delete Items ON keep ON if Manco must delete; off if deletion is admin-only the only switch that decides who may delete across the workspace

If staff need to raise work without create rights: put a Form view on their list and share the form. Submissions arrive as new tasks; the staff member still holds Edit, so the "no create" rule holds.

6. Limit worth knowing

On Business nothing stops a staff member at Edit level from archiving, merging or moving a task out of its list — ClickUp exposes no separate switch for those. If that gap must be closed as well, the only complete answer is Enterprise (custom roles + Space-level permissions), which is a money decision for Ricardo.
