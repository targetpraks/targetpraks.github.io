05 Method and its limits

What was executed, not read:
  • 32 live site probes — one HTTPS request each, TTFB and transfer size recorded (curl, 25 s ceiling, browser UA).
  • 25 GitHub repos matched from official links on each vendor site — stars, forks, contributors, commits since 2026-08-07, licence, archive state via REST API.
  • npm registry — package existence, latest version, last-week downloads for the 12 tools that ship via npm.
  • 6 installer endpoints — install.sh / setup.sh fetched and inspected for a live shell script.
  • Scoring — percentile ranks within the set, so no absolute-scale choice can flatter anyone; weights declared above, applied identically to all 32.
What this cannot tell you: which tool feels best after a week of real work. That is a hands-on question and needs a 2-day trial per shortlist, not a webpage. Numbers here sort the field; your hands rank the shortlist.

Known blind spots: closed-source tools (Agentastic, Solo, super.engineering, Maestri, Clor, Conductor, Reliant) score 0 on velocity and reach because they publish no repository — that measures transparency, not quality. Reliant publishes almost nothing at all and cannot be assessed.

Read this before reading the list: not one of the 32 tools includes a model. Every one is a shell around agents you already pay for — "bring your own subscription" is the phrase that appears on most of these sites, because the Claude Code / Codex / Cursor bill is yours.

That means a free app is not a free setup. Only four of them document pointing at a local, unpaid model: Hermes (any OpenAI-compatible endpoint, including Ollama), Pi (Ollama, OpenRouter, 15+ providers), omp ("API-key, OAuth, subscription, gateway, or local providers") and OpenCodeX (40+ providers incl. Ollama). Those four are the only genuinely zero-cost end-to-end options on the list — and OpenCodeX is a gateway, not an orchestrator.

Everything else in the FREE column costs nothing to install and then asks for someone else's subscription key to do anything at all.
