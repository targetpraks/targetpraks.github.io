Opening the Zoho Tables API lane

Ten steps. One scope string. It ends with me able to build and maintain the document register without asking you for anything again.

For: Ricardo  ·  Prepared by: Bruce Wayne  ·  Date: 3 November 2026  ·  Time needed: about 4 minutes

Why this is needed

Tested against the live API this morning, with the token we already hold:

CapabilityResult today
ReadWorks — I read all 74 bases, the ten department workspaces, and CODA Doc Tracker's fields and records
Create baseWorks
Create recordWorks — wrote one, read it back
Create fieldRefused — so I cannot build the columns
Delete record, table or baseRefused — INVALID_OAUTH_SCOPE
A register I can add rows to but cannot put columns in is a library with no shelves. Five extra operations fix all of it, and it also means the Zoho MCP toggle is no longer needed for this work — the REST lane covers everything.

The steps

1

Open the API console

In Dia (that's the browser carrying your Zoho session): api-console.zoho.com

2

Choose the Self Client

On the clients list, pick the row marked Self Client — not a Server-based client. It already exists; do not create a new one. The detail panel opens on the Generate Code tab.

3

Paste the scopes

The full 98-scope string is already on your clipboard, copied from the fleet auth script. Click the Scope field and paste. It is long — that's correct.

The one place this matters is the Tables module list — every module spelled out:

ZohoTables.bases.CREATE / .DELETE
ZohoTables.tables.CREATE / .DELETE
ZohoTables.fields.CREATE / .UPDATE / .DELETE
ZohoTables.records.DELETE
ZohoTables.views.CREATE

Not ZohoTables.fullcontrol.ALL — Zoho's own API page prints that scope, and the console rejects it as invalid. The client only knows the per-module names.

If the clipboard has been overwritten, put it back with:

python3 ~/.hermes/scripts/zoho-auth.py --new-code zoho-all | pbcopy
4

Set the duration to 10 minutes

Click the time dropdown and choose 10 minutes. The default of three is too tight for the paste.

5

Type a plain description

Letters, digits and single spaces only. For example:

Zoho fleet full access 20261103

Type it, don't paste it. Brackets, slashes and spaced dashes are rejected with "Enter a valid description" even though the counter looks right.

6

Click CREATE

If the console names invalid scopes, it shows a Remove link beside each one. Remove those and press CREATE again — the scope string is otherwise settled, so this should be a clean pass.

7

Copy the generated code

The result panel shows a code starting 1000. — about 70 characters. Press COPY. Do not retype it.

The clock is now running. Generate the code and run step 8 inside the ten minutes, or it expires and you start again at step 6.
8

Exchange it for the token

In a terminal on this Mac:

python3 ~/.hermes/scripts/zoho-auth.py --grant zoho-all --from-clipboard

It reads the code from the clipboard, stores the refresh token in the fleet secrets store, mints an access token, and fires one read-only probe per Zoho service.

9

Read the probe output

You want Tables portals to answer 200 alongside the rest. Anything red there means the scope didn't take and we go back to step 3.

10

Tell me it's done

Two words is enough. I'll re-run the write tests, then build the register in a single pass.

If something goes wrong

  • "Enter a valid description" — retype it plainly, letters and digits only. Pasting is the usual culprit.
  • A number-match push to your phone — only you can tap it. The push expires in about a minute; hit Resend Push and use the fresh number. Do not take the password route.
  • "invalid_code" — the code expired or was already used. Generate a fresh one and run step 8 immediately.
  • "No valid scopes" — the paste didn't land. Check the field isn't empty before CREATE.
  • Ten-code limit — Zoho meters code generation at roughly ten per ten minutes. If you hit it, wait it out; nothing is broken.

What happens after

  • Base 18 goes. The empty probe base in INF ADMINISTRATION, and the stray test record inside it, both delete the moment the scope lands.
  • The register is built. Base INF Document Register in INF ADMINISTRATION — one table, eight fields, a saved view per department.
  • It's seeded. The eleven documents from the old 9 Docs That Run This Business index, plus what legal and licence already track, with duplicate and empty rows dropped.
  • You get the link and a first read on which departments are bare.
Reference: the endpoint behaviour above comes from Zoho's own Tables API v1 documentation. The app itself is at tables.zoho.com.
